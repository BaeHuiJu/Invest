## 1. Overview

### 1.1 Purpose

글로벌픽의 핵심 비전인 "투자 지침서" 역할을 실현하기 위해, DEVELOPMENT_PLAN.md에 정의된 미완료 기능 중 투자 지침서 관점에서 임팩트가 큰 항목들을 우선 구현한다.

이전 갭 분석(`/pdca analyze 투자가이드`, 2026-04-22)에서 도출한 핵심 과제:
- P0 갭: 종목 카드에서 투자 근거 미노출 (클릭 후 팝업에서만 확인 가능)
- P1 갭: 시장 해설 없음 (지수 숫자만 표시)
- P1 갭: 알림 UI만 있고 실제 push 배송 없음
- P1 갭: 실적 추정치 시계열 차트 없음

### 1.2 Background

DEVELOPMENT_PLAN.md 기준 현황:
- 완료: 4개 (PWA, AI추천 시스템, 컨센서스 변화 추적, 애널리스트 리더보드)
- 미완료: 21개 (84%)
- 최우선(⭐⭐⭐⭐): 맞춤형 알림 시스템, 실시간 포트폴리오 추적

### 1.3 Related Documents

- Gap Analysis: `readme/customer-investment-guide-features.md` (비전 문서)
- Dev Plan: `DEVELOPMENT_PLAN.md` (전체 로드맵)
- Prior Analysis: `/pdca analyze 투자가이드` 결과 (Match Rate 70%)

## 2. Scope

### Phase 1 — Quick Win (이번 구현 대상)

- [ ] **FR-01** 종목 카드에 투자 근거 1줄 요약 직접 노출
  - 대상 탭: AnalystTab, ConsensusTab, AIPicksTab
  - `reasonBullets[0]` 또는 `reasonSummary` 를 카드/행에 직접 표시
  - 현재: 클릭 → 팝업 → 확인 (3단계) → 목표: 카드에서 즉시 확인 (0단계)

- [ ] **FR-02** HomeTab 시장 해설 카드 추가
  - 주요 지수 섹션 아래 "오늘의 시장" 해설 텍스트 카드
  - 데이터 기반 자동 생성: 지수 등락폭 → 간단한 규칙 기반 해석 텍스트
  - 초보자 언어 ("코스피가 1% 이상 올랐습니다 → 시장 전반적으로 긍정적인 하루")

### Phase 2 — Core (알림 시스템 완성)

- [ ] **FR-03** 브라우저 push 알림 실제 배송 구현
  - 현재: `NotificationSettings` UI + 권한 요청만 구현됨
  - 추가 필요: Service Worker push event handler, VAPID 키 설정
  - 트리거: 관심 종목 새 리포트 발행 시 (캐시 갱신 후 비교)
  - 기존 `lib/notification-settings.ts` + `next-pwa` Service Worker 활용

- [ ] **FR-04** 목표가 도달 알림
  - 관심 종목 currentPrice ≥ targetPrice × 0.95 시 알림
  - GitHub Actions 캐시 갱신 주기(30분)와 연동

### Phase 3 — Enhancement (선택적)

- [ ] **FR-05** 실적 추정치 방향 인디케이터
  - 현재: 팝업 내 `estimateRevision` 텍스트만 존재
  - 추가: 상향(↑) / 하향(↓) / 보합(→) 아이콘을 종목 카드에 표시
  - 별도 시계열 차트는 이번 범위 외 (데이터 부재)

### Out of Scope

- 개인 투자 기록 기반 맞춤 피드백 (DB 필요, 별도 기획)
- 이메일 알림 (Resend/SendGrid 연동 필요, 별도 스프린트)
- 실시간 포트폴리오 추적 (WebSocket/폴링, 별도 스프린트)
- WebSocket 실시간 가격 (인프라 변경 필요)

## 5. Risks and Mitigation

| Risk | Impact | Likelihood | Mitigation |
|------|--------|------------|------------|
| Safari push 알림 미지원 (iOS 16.3 이하) | High | High | iOS 사용자에게 안내 문구 표시, 브라우저 감지 후 조건부 UI |
| VAPID 키 관리 (환경변수 노출 위험) | High | Low | Vercel 환경변수로 서버사이드 보관, 클라이언트에 공개 키만 노출 |
| `reasonSummary` 빈 값 (일부 종목) | Medium | Medium | 빈 값 시 카드에 공란 처리 (레이아웃 유지) |
| next-pwa Service Worker와 push 이벤트 충돌 | Medium | Low | custom SW 파일 (`public/sw-push.js`) 별도 등록 방식 검토 |
| 시장 해설 규칙 기반 텍스트 오해 소지 | Low | Medium | "AI 해설 아님, 데이터 기반 요약" 명시, 면책 문구 추가 |

## 7. Architecture Considerations

### 7.1 Project Level Selection

| Level | Selected |
|-------|:--------:|
| Starter | ☐ |
| **Dynamic** | ✅ |
| Enterprise | ☐ |

기존 Next.js 14 Pages Router + 정적 JSON 캐시 구조 유지. 알림 API만 신규 추가.

### 7.2 Key Architectural Decisions

| Decision | Selected | Rationale |
|----------|----------|-----------|
| Push 방식 | Web Push API + VAPID | 서버 인프라 최소화, next-pwa와 호환 |
| 구독 저장 | localStorage (MVP) | DB 없이 클라이언트 단 저장, 추후 DB 마이그레이션 가능 |
| 시장 해설 | 규칙 기반 (서버사이드) | LLM 비용 없음, 빠른 응답, 신뢰도 제어 가능 |
| 투자 근거 노출 | `reasonSummary` 직접 표시 | 기존 데이터 재활용, 추가 API 불필요 |

### 7.3 Folder Structure Preview

```
pages/
  api/
    push-subscribe.ts   (신규) - VAPID 구독 엔드포인트
    push-notify.ts      (신규) - 알림 발송 API
public/
  sw-custom.js          (신규) - push 이벤트 핸들러
lib/
  notification-settings.ts  (수정) - push subscription 함수 추가
  market-commentary.ts  (신규) - 시장 해설 규칙 엔진
components/
  AIPicksTab.tsx        (수정) - 투자 근거 1줄 추가
pages/
  index.tsx             (수정) - AnalystTab/ConsensusTab 행 수정, HomeTab 해설 카드 추가
```
