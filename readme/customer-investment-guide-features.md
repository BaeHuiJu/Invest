# 투자 지침서 관점 기능 정리

## 개요

글로벌픽은 단순히 종목을 나열하는 추천 사이트가 아니라, 일반 고객이 "무엇을 보고", "왜 투자하는지", "지금 행동해도 되는지"를 이해할 수 있게 돕는 투자 지침서가 되어야 한다.

일반 고객은 숫자 자체보다 아래 질문에 대한 답을 원한다.

- 지금 시장에서 무엇을 먼저 봐야 하는가
- 이 종목을 왜 추천하는가
- 지금 가격이 비싼지 싼지
- 리스크는 무엇인지
- 지금 사도 되는지, 기다려야 하는지
- 산 뒤에는 무엇을 체크해야 하는지

따라서 서비스는 `데이터 조회`보다 `이해`, `비교`, `판단`, `추적`을 중심으로 기능이 설계돼야 한다.

## 제품 원칙

- 이해하기 쉬워야 한다: 금융 용어를 그대로 던지지 말고 일반 고객 언어로 해석해야 한다.
- 근거가 보여야 한다: 추천에는 리포트, 실적, 밸류에이션, 업황 같은 근거가 함께 보여야 한다.
- 행동으로 이어져야 한다: 관심 종목 저장, 알림, 목표가/리스크 확인처럼 다음 행동이 분명해야 한다.
- 사후 점검이 가능해야 한다: 추천 이후 성과와 변화 이유를 계속 추적할 수 있어야 한다.

## 1. 시장을 빠르게 이해하는 기능

### 고객 문제

일반 고객은 어떤 종목을 보기 전에 지금 시장 상황이 위험한지, 기회가 있는지부터 알고 싶어 한다.

### 필요한 기능

- 국내/해외 주요 지수 한눈에 보기
- 오늘 시장 요약
- 시장 분위기 해설
- 업종별 강세/약세 정리
- 주요 이벤트 캘린더

### 왜 필요한가

- 종목 추천만 보면 시장 전체 흐름을 놓치기 쉽다.
- 같은 종목도 시장 국면에 따라 접근 방식이 달라진다.
- 초보 투자자는 "왜 오늘 이 종목이 중요한지"를 시장 배경과 함께 봐야 이해가 된다.

### 우선순위

- `P0`: 주요 지수, 시장 요약, 업종 강세/약세
- `P1`: 이벤트 캘린더, 시장 해설 카드
- `P2`: 거시 변수와 시장 영향 연결 설명

## 2. 종목을 비교하고 고르는 기능

### 고객 문제

일반 고객은 종목이 많으면 무엇부터 봐야 할지 모른다. 추천 종목 목록만으로는 선택 근거가 부족하다.

### 필요한 기능

- 애널리스트 추천 종목 모아보기
- 여러 증권사가 동시에 추천한 종목 모아보기
- 국내/해외/ETF 별 비교 화면
- 정렬과 필터 기능
- 관심 종목 저장 기능

### 왜 필요한가

- 사용자는 먼저 후보군을 좁혀야 한다.
- 복수 증권사가 동시에 추천한 종목은 신뢰 신호로 받아들여진다.
- 관심 종목 저장은 반복 방문과 비교 행동의 기본이다.

### 우선순위

- `P0`: 추천 목록, 공통 추천, 기본 필터/정렬, 관심 종목 저장
- `P1`: 사용자 성향별 추천 분류
- `P2`: 포트폴리오 목적별 추천 묶음

## 3. 왜 사야 하는지 설명하는 기능

### 고객 문제

일반 고객은 "추천"보다 "왜 추천하는지"를 알고 싶어 한다. 숫자만 있어서는 확신이 생기지 않는다.

### 필요한 기능

- 종목 한줄 요약
- 추천 논리 설명
- 실적 추정치 변화
- 밸류에이션 설명
- 업종 사이클 설명
- 관련 리포트 원문 링크

### 왜 필요한가

- 일반 고객은 애널리스트 리포트를 직접 다 읽기 어렵다.
- 종목을 사는 이유가 실적, 업황, 밸류에이션 중 어디에 있는지 구분해줘야 한다.
- 원문 링크는 신뢰를 높이고 더 깊은 확인을 가능하게 한다.

### 우선순위

- `P0`: 추천 논리, 기준가격 대비 현재가, 리포트 링크
- `P1`: 실적 추정치 변화, 밸류에이션, 업종 사이클
- `P2`: 경쟁사 비교, 과거 추천 근거 변화 추적

## 4. 관심 종목을 추적하고 행동으로 이어지는 기능

### 고객 문제

좋아 보이는 종목을 발견해도, 나중에 다시 확인하거나 매수 타이밍을 잡는 과정이 어렵다.

### 필요한 기능

- 관심 종목 저장
- 목표가 대비 현재 위치 표시
- 추천 이후 가격 변화 추적
- 새 리포트 발행 알림
- 목표가 변경 알림
- 투자 의견 변경 알림

### 왜 필요한가

- 투자 판단은 한 번 보고 끝나지 않는다.
- 사용자는 "지금 들어가도 되는지"와 "상황이 바뀌었는지"를 계속 확인해야 한다.
- 반복 추적 기능이 없으면 서비스가 조회형으로 끝난다.

### 우선순위

- `P0`: 관심 종목 저장, 현재가/기준가격/목표가 비교
- `P1`: 새 리포트 및 목표가 변경 알림
- `P2`: 개인별 매수가 기록과 수익률 추적

## 5. 매수 후 점검과 학습 기능

### 고객 문제

매수 이후에는 왜 계속 보유해야 하는지, 언제 다시 판단해야 하는지 모르는 경우가 많다.

### 필요한 기능

- 추천 이후 성과 추적
- 실적 발표 전후 체크포인트
- 리스크 요인 정리
- 손절/분할매수/목표가 달성 시 행동 가이드
- 초보자용 용어 설명

### 왜 필요한가

- 일반 고객은 매수보다 사후 관리에서 더 많이 흔들린다.
- 투자 판단 기준을 제공해야 서비스가 진짜 지침서 역할을 한다.
- 학습형 설명이 쌓이면 재방문 이유가 된다.

### 우선순위

- `P0`: 리스크 요인, 초보자용 용어 설명
- `P1`: 추천 이후 성과 추적, 실적 발표 체크포인트
- `P2`: 개인화된 투자 학습 가이드

## 일반 고객 관점 핵심 기능 우선순위

### P0

- 시장 요약과 주요 지수
- 애널리스트 추천 종목
- 여러 증권사 공통 추천
- 종목을 왜 사야 하는지 요약
- 기준가격 대비 현재가 비교
- 관심 종목 저장
- 리포트 원문 링크
- 초보자도 이해할 수 있는 설명

### P1

- 실적 추정치 변화
- 밸류에이션 해설
- 업종 사이클 해설
- 목표가/의견 변경 알림
- 추천 이후 성과 추적

### P2

- 투자 성향별 추천
- 포트폴리오 구성 가이드
- 개인 투자 기록 기반 맞춤 피드백
- 학습형 콘텐츠와 시나리오 가이드

## 현재 기능과의 연결

### 현재 이미 있는 기능

- 애널리스트 추천 종목 조회
- 공통 추천 화면
- 기준가격과 현재가 비교
- 종목 클릭 시 인사이트 팝업
- 관련 리포트 링크
- 관심 종목 저장
- 모바일 반응형 화면

### 아직 더 필요한 기능

- 초보자용 시장 해설
- 종목별 리스크 관리 가이드
- 실적 추정치 변화의 시계열 표현
- 추천 이후 성과 추적 화면
- 알림 기능
- 포트폴리오 단위 투자 가이드

## 결론

일반 고객 입장에서 좋은 투자 서비스는 추천 종목이 많은 서비스가 아니라, 추천의 이유와 이후 행동 기준을 명확히 알려주는 서비스다.

글로벌픽이 투자 지침서가 되려면 앞으로의 기능 개발 기준은 아래 한 문장으로 정리할 수 있다.

`무엇을 사야 하는가`보다 `왜 사야 하는가`, `지금 사도 되는가`, `산 뒤에는 무엇을 봐야 하는가`를 설명하는 기능이 우선돼야 한다.
